# Noto Sans TC font source

- Family: Noto Sans TC (Google Fonts, variable weight)
- Official font source: https://github.com/google/fonts/tree/main/ofl/notosanstc
- Source font file: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanstc/NotoSansTC%5Bwght%5D.ttf
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanstc/OFL.txt
- The original upstream OFL file is retained unchanged as `NotoSansTC-OFL.txt`.
- `NotoSansTC-Big5Level1.ttf` is a variable-font subset containing Big5 level-1 Hanzi plus the authored game glyphs; regular, medium and bold runtime variations reference its `wght` axis.

The full upstream font binary is not shipped. The subset and exact license text are included with the project.
