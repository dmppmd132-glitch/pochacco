# 嘟嘟與帕恰狗：點心島的奇幻野餐

一款繁體中文 Godot 4 2D 平台冒險遊戲原型，匯出為可安裝的 PWA。目前有兩個完整章節與一個可試玩的第三章灰盒，玩家可以即時切換嘟嘟與帕恰狗，未操控角色會由 AI 隨行。

## 遊玩

GitHub Pages 公開遊戲：[https://dmppmd132-glitch.github.io/pochacco/](https://dmppmd132-glitch.github.io/pochacco/)。標題頁可選擇第一章、第二章或試玩第三章「糖霜齒輪城」灰盒；第一、二章有完整結算流程，第三章已加入發條糖果守衛戰與鐘芯結算流程，仍在調整雙齒輪謎題、互動與路徑手感。完整安裝與操作指南見 [PLAYING.md](PLAYING.md)。

iPhone／iPad 請以 Safari 開啟網址，選「分享」→「加入主畫面」，再從主畫面圖示啟動並橫向遊玩。首次載入需下載約 54 MB 遊戲資源，請先連接穩定網路並等到標題畫面出現。Service Worker 會在首次完整載入時快取遊戲本體；離線重啟及手機觸控手感尚待實體裝置驗證。

## 章節內容

- **第一章｜草莓蛋糕村**：探索甜點平台、收集星星糖與草莓食材；用帕恰狗嗅聞找出隱藏巧克力牆，再切換嘟嘟滾撞破牆。果醬河需要兩位角色合作，最後以香蕉皮和屁屁坐擊擊敗哼哼奶油怪，走到草莓噴泉閥門完成本章。起點戚風彈跳台已降低，沿地面靠近後起跳即可接上彈跳路線。
- **第二章｜棉花糖雲朵森林**：帕恰狗嗅出雲朵風車的風鈴線索，再以香蕉迴旋鏢敲響風鈴開啟雲門。利用彈跳雲朵與上升氣流前進，穿越週期性側風走廊（風起時會推回，等候平靜空檔或持續向前移動）；在雲朵橋讓帕恰狗守住踏板、由嘟嘟打開通路；最後先敲出棉花糖風靈的月光鈴心，再用嘟嘟屁屁坐擊，走到月光蜂蜜鈴完成本章。
- **第三章｜糖霜齒輪城（灰盒）**：包含低位安全路線與高位高風險星星糖分支（多 3 顆），並在高風險路線配置三座錯相蒸汽噴口；噴口具 0.8 秒預熱、0.9 秒噴發、約 1.9 秒冷卻，失誤會把角色彈回安全平台。帕恰狗嗅嗅可預告附近噴口狀態，嘟嘟坐擊可壓閥 2.4 秒；分支在鐘樓檢查點前匯合。章末發條糖果守衛會施放可跳躲的齒輪波紋與慢速擺錘；帕恰狗敲中黃銅卡榫後，嘟嘟須在 3.5 秒內坐擊露出的鐘芯，累積三次命中，打開閘門後觸碰星星糖鐘芯通關。Boss 現有六組原創 WAV cue，命中加入模型反衝、爆光、相機震動及短暫打擊停頓；雙齒輪組合謎題、互動高亮及齒輪載人實機驗收仍待完成，詳見 [TODO.md](TODO.md)。

三章皆有星星糖與章節食材可收集。標題頁衣櫃、服裝資料與購買／保存已接線；章節結算星星糖入帳及角色實際服裝外觀套用仍列於 [TODO.md](TODO.md)。

新增七組三章地標雙角色繁中短對話，對話不暫停遊戲、依角色／路線條件只觸發一次；靠近隊友切換角色可觸發有冷卻的擊掌反應。PWA 端補上觸控回歸驗收，確認搖桿主指標捕捉與失焦時釋放跳躍輸入，並調整窄螢幕對話字級／文字區。程式層級效能改善包含背景繪製節流至 30Hz、靜態收集品取消每幀重繪、角色裝飾層降至 10Hz；另將 2D Stretch Mode 改為 `viewport`。同源手機模擬 A/B 的畫格中位間隔由 100ms 降至 83.3ms，觸控後首個畫面回呼約改善 23–27%；這是軟體渲染器數據，不等同實體手機 FPS，詳見 [MOBILE_WEB_TEST.md](MOBILE_WEB_TEST.md)。

第四章提案為「月潮玻璃海」，包含回音音序、折光鏡面、可選風險支線與三階段潮汐水母王；這是規劃文件，不代表第四章已有可玩實作，詳見 [CHAPTER_4_PLAN.md](CHAPTER_4_PLAN.md)。本輪互動、觸控與效能變更目前尚未同步至 GitHub Pages。

第一章開場跳台路線已調整並加入 smoke regression：測試會實際從地面跳上戚風彈跳台、觸發彈跳、落到下一塊餅乾平台並拾取星星糖；第二章測試也會檢查側風作用區、推力及風歇窗口。`npm run test:chapter-three` 另驗收蒸汽噴口、守衛狀態機、Boss 音效路由、嘟嘟實際落地坐擊、打擊回饋與真實章末閘門／鐘芯通關流程；`npm run test:dialogue` 驗收三章地標對話、擊掌、觸控搖桿指標捕捉與失焦釋放。六組 Boss WAV 亦在隔離使用者資料目錄中通過音效完成測試。完整 `npm test` smoke suite 已通過。

## 操作

### 鍵盤

- 移動：`←`／`→` 或 `A`／`D`
- 跳躍：`Space` 或 `↑`
- 切換角色：`L` 或 `Tab`
- 主要能力：`J` 或 `X`（嘟嘟滾滾衝刺／帕恰狗香蕉迴旋鏢）
- 嘟嘟屁屁坐擊：跳起後按 `K`
- 帕恰狗偵探嗅嗅：`E`
- 帕恰狗放香蕉皮：`C`
- 集合／雙重重量機關：`F`
- 攻略／帕恰狗香蕉皮：`R`（嘟嘟顯示本章攻略；帕恰狗放香蕉皮）
- 暫停：`Esc`

### 手把與手機觸控

| 按鍵 | 動作 |
| --- | --- |
| `A` | 跳躍 |
| `B` | 嘟嘟滾滾衝刺／帕恰狗香蕉迴旋鏢 |
| `X` | 嘟嘟屁屁坐擊／帕恰狗偵探嗅嗅 |
| `Y` | 集合抱抱 |
| `L`（左肩鍵） | 切換角色 |
| `R`（右肩鍵） | 嘟嘟攻略說明／帕恰狗放香蕉皮 |
| `Start` | 暫停 |

手機請橫向持握。左側虛擬搖桿負責左右移動，上推可跳躍；右側使用仿手把的 `A`／`B`／`X`／`Y` 按鍵及 `L`／`R` 肩鍵。

## 專案與部署

遊戲原始碼位於專案根目錄。GitHub Pages 部署 `github-pages/` 中的自包含 PWA（含 `index.wasm`、`index.pck`、manifest、Service Worker 與離線頁）；`.github/workflows/pages.yml` 會在 `main` 分支更新時，依 `assets.lock.json` 還原並驗證素材、安裝 Godot 4.7.2 與 Web 匯出模板、執行平台／陣風／第三章 Boss／故事對話與來源契約測試、匯出及檢查 PWA，再同步並部署 GitHub Pages。也可從 Actions 頁面手動執行 workflow。Webdev 管理的 `site/` 是另一份預覽輸出，不是 GitHub Pages 的部署來源。

更新遊戲並推送到 `main` 後，GitHub Actions 會自動完成建置與部署；本機也可用 `npm run ci:hydrate-assets` 還原鎖定素材、`npm run ci:export` 匯出 `dist/standalone/`，再用 `npm run pages:sync` 更新 Pages 目錄。同步腳本會排除本機 build fingerprint，並確認 PWA 包含 WASM/PCK 且沒有 Manus Storage 絕對路徑。

驗證第一章開場平台可達、彈跳、落到下一平台並取得糖果：`npm run test:platform-route`。驗證第二章週期陣風的區域邊界、活動／平靜週期與角色實際受側推：`npm run test:cloud-gust`。第三章噴口相位、錯相配置、嗅嗅提示與坐擊壓閥：`npm run test:chapter-three`。Pages workflow 會在實際匯出的 PCK 上重跑前兩項測試；第三章測試目前在原始碼環境執行。
